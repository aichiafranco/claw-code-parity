# jiejin-watch

自动抓取 **解禁期前** 的 A 股限售解禁名单。数据来自东方财富数据中心公开 JSON 接口（与 [限售股解禁详情](https://data.eastmoney.com/dxf/detail.html) 同一套），按解禁市值排出大额 TopN，写成和 Obsidian 笔记类似的索引：

`YYYYMMDD-大额解禁Top100图谱索引_100只.md`

每条附带解禁页、公告页、「简称+解禁」资讯搜索链接；报告里还有 **解禁临近** 和 **全市场解禁日历**。走公开 JSON，不去爬整站 HTML。

## 用法

```bash
cd rust
cargo run -p jiejin-watch -- \
  --days 60 \
  --top 100 \
  --min-yi 1 \
  --output "./投资分析/08-板块资金与大盘"
```

常用参数：

- `--days` 从今天起往后看多少天（默认 60）
- `--top` 按解禁市值取前 N（默认 100）
- `--min-yi` 最低解禁市值（亿元，默认 1）
- `--holders` 再抓 Top 名单的解禁股东
- `--near 7` 单独列出未来 N 天内临近解禁
- `--code 300008` 只跟踪一只股票
- `--no-calendar` 不写全市场按日解禁日历
- `--as-of 20260908` 指定基准日，便于复盘

## 说明

东财把解禁数量/市值按「万」返回，工具在表里把市值换算成亿元。分页之间默认停 200ms。这是公开行情数据的只读拉取，请合理间隔、仅作研究使用。
